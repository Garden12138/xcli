# 安全边界

仅 loopback IP 监听，禁止 LAN/公网地址。独立本地 App Token 至少 256-bit 随机熵、最小模型权限、撤销/轮换、限速；客户端 Token 与上游 API Key 不共用。凭据只通过受限私有文件或环境引用提供，不出现在 argv、错误、日志、仓库中。默认无浏览器 Origin/CORS。

网关不执行 shell、不读取模型消息中的路径、不创建 Task、不继承原生 Agent 的 MCP 或登录凭据。不提供 CLI 订阅桥接。若要实验，必须独立核对品牌、登录方式、厂商官方许可、用户明确授权、工具禁用和停止机制；不明确则不启用。现有 headless CLI 能力不自动证明可共享会员额度。

请求/响应、SSE 事件、图片字节/像素、并发、超时均需有界。默认不保留内容；只记录随机请求 ID、状态码/错误类别、耗时与计数，不记录 prompt、图片、token、上游响应正文。上游错误信息由本地稳定文案替代。无遥测。

图片不读文件路径；上传文件名不用于落盘。URL 输入保守拒绝，URL 输出未具备白名单/DNS/重定向检查时拒绝。不会为兼容任意 URL 关闭 SSRF 防护。

应用同意与网关权限同时约束数据传输。Chat Insight 在其 effective_cloud 修复、索引隔离和拒绝授权测试通过前，不可正式接入远程模型。四应用各自原有权限/冻结 Profile/审计/沙箱不被 xcli 授权替代。
