# Native Agent Gateway V1 — Requirements

状态：Proposed，2026-11-06；实现与真实 HTTP→CLI 验收均未完成。术语 MUST/必须表示验收硬条件；SHOULD/建议表示可记录理由调整的工程选择。

## 事实与目标

[本轮报告](../cli-first/ACCEPTANCE_REPORT.md)记录 9 次原生启动：Codex、Antigravity 各完成文本、新会话后续接、单图生成、参考编辑；Cursor 一次文本启动被 workspace trust 阻断，其续接/媒体未执行。离线 HTTP 模型测试、历史媒体记录、厂商帮助和本轮推理是不同证据。

目标是让本人本机应用提交**有权限、预算和结果验证的 Agent 任务**，复用已安装的官方原生客户端。`agent_id` 代表执行入口，不代表底层模型；一次 Agent 任务可能包含多个模型轮次、重连、工具与子代理。服务不承诺订阅账号可作为第三方通用推理 API、免费运行、精确计价或完整 Chat Completions 语义。

## V1 必须满足

| ID | 需求 | 可判定结果 |
| --- | --- | --- |
| R01 | 独立 Agent API、配置、客户端授权、数据根和端口；不接入 model.ChatBackend | `/agent/v1` 与 `/v1` 分开；原 `native-cli` 类型仍拒绝 |
| R02 | 文本任务与最终文本；一个任务仅提交一个原生 turn，不运行多轮 Task 协调器 | 返回结构化执行/协议/验证状态；业务输出不依赖 stdout 文案猜成功 |
| R03 | 逻辑 Session 创建、同 Session 续接、关闭及归属控制 | 创建不调用模型；首次任务绑定原生 ID；只能同客户端、同适配器/策略续接 |
| R04 | 能力发现包含版本、来源、证据范围、时效和当前阻断原因 | 未安装、未验收、trust、认证未知、版本漂移分别表达；发现不消耗推理额度 |
| R05 | 任务状态机及结果错误稳定、可重连查询、可审计 | 退出 0、终止事件、文件/业务校验均独立保留；不完整输出不落为成功 |
| R06 | 实时活动事件、终止事件和有限重放；原生增量另作能力 | 无原生 delta 时只报活动及最终文本引用，不把整段结果切片冒充增量 |
| R07 | 单张图片生成与单参考图编辑，交付真实原始字节 | 验证格式/完整解码/尺寸/哈希/归属/原图不变；来源与视觉审查通过才可接收 |
| R08 | 取消、截止时间、并发、排队与会话串行 | 请求取消不等于停止；未知云副作用标记 reconcile；超时/断连不重发 |
| R09 | 可执行的最小工作区/工具/网络策略与权限失败关闭 | API 无 cwd/argv/env/原生 session 参数；不能执行策略时明确 BLOCKED |
| R10 | 不可观测账号额度时使用本地可强制预算、明确失败语义 | 启动/dispatch 预扣，失败不返次数，无自动重试/fallback/换账号；费用未知为 null |
| R11 | 独立应用授权和每次云同意，限制材料/日志/留存 | remote/unknown 都要同意；不读取登录凭据，不把应用 Token 传给 CLI |
| R12 | 四应用独立 Agent 模式的适配协议及能力拒绝 | 文本/媒体按各自流程接入；原生 Embedding、完整 RAG、严格 Schema 不假称支持 |
| R13 | 官方程序集成优先调查；传输可替换但会话固定 | exec、SDK、app-server 的认证、生命周期和依赖分别评估，不静默切换 |
| R14 | 服务重启、事件/结果持久化、幂等及回退 | 已 dispatch 未知状态不重放；不能从历史 PID 直接 kill；新存储不破坏旧 Run/Task |
| R15 | 每阶段验收可复现，真实调用另立授权与预算 | 离线、真实 CLI、HTTP→CLI、应用 UI 的结果分别记录 |

## 最小功能边界

V1 操作为 `text_task`、`image_generate`、`image_edit`。文本只有 user 任务及选定 UTF-8 材料；不接收任意 role history。Session 包含本任务领域已批准的累计上下文；应用不能把不同用户、项目或私密材料混入同一个 Session。图片固定 1 个输出、编辑固定 1 个参考，不承诺尺寸、mask、透明背景、任意模型或格式转换。

V1 提供权限检查和拒绝；**不提供工具自动批准，也不提供通用在线批准工具 API**。headless 无法完成必要审批时终止为 blocked；用户通过官方流程检查权限后，以新的显式请求继续，仍受累计预算限制。图片结果的人工接收不授予工具权限。

默认并发全服务 1，同原生安装域 1，同 Session 1；实现可配置有上限的并发，但未经真实隔离验收的域保持 1。取消/超时的本地进程收敛是必须能力，厂商云任务撤销仅能报告真实可观测的确认。

## 非目标与明确缺口

| 项目 | V1 处理 |
| --- | --- |
| OpenAI Chat Completions、Responses、Images 全兼容 | 不提供；现有 HTTP Model Gateway 保留原功能 |
| 共享订阅、账号池、转售、代理第三方任意推理 | 不设计、不启用；本机封装不是许可证明 |
| 原生登录 Token/Cookie/Keychain 导出、私有端点 | 禁止；只由官方原生进程自行使用已有登录 |
| 原生 Embedding | 无已验证接口；拒绝。Chat Insight 的向量服务另选合法后端 |
| 任意 Vision、严格原生 JSON Schema、应用 tool_calls | 本轮 NOT_TESTED；V1 不能由事件 JSON 或图片编辑推导支持 |
| 代码仓库自主多轮规划/修复/发布 | 不自动调用现有 `internal/task.Runner`；另立工作流范围 |
| LAN/公网、多租户、浏览器直连、Docker 宿主桥接 | V1 不开放；Contribution OS 容器路径明确拒绝 |
| 音频/视频、MCP 暴露、远程工具执行 | 不在 V1；已配置全局工具也不能隐式继承 |

## 四应用最低适配目标

| 应用 | 可设计接入的能力 | 尚未实现/不能开放 |
| --- | --- | --- |
| Worklog | 用户选材的日报、周报、模板草稿、Session 续改；应用本地校验 JSON | Agent transport/UI 全部未实现；没有原生严格 Schema 保证 |
| GardenFlow | 文本任务、生成/编辑任务、认证字节下载、预览后显式入库 | Agent/Artifact transport、入库状态机未实现；Vision/mask/n/size 未验收 |
| Chat Insight | 用户选段总结与续问、真实事件进度 | Agent 模式未实现；原生 Embedding 缺失，完整 CLI RAG 不成立 |
| Contribution OS | 宿主环境的只读 Plan/Review 草稿，本地业务校验、冻结 Profile | Agent provider、受控 Run、严格输出及 Docker 桥接未实现；发布能力不授予 |

这些是未来适配目标，不是四应用当前已可调用的能力。[迁移与协议](MIGRATION_AND_COMPATIBILITY.md)列出各自模块和拒绝条件。
