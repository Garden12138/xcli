# R3 独立用户观察脚本与记录表

状态：**尚未招募或完成本阶段独立用户观察**。以下是待使用的脚本与空白记录，不是验收结果。首批三位已有原生 CLI 使用经验的参与者分别操作；维护者不代操作，也不通过自动化夹具填写记录。没有默认遥测。

## 参与者操作

开始前由参与者确认工具账号与预算，使用不含秘密的材料和可丢弃项目。观察者只记录，不先解释操作；发生求助时记录原话、时间和帮助内容。

1. 按候选版说明安装、核对版本并运行 doctor。记录从开始安装到首次 Task 成功的耗时，包括下载、登录和额度阻力。
2. 选择一项自己的 Work 或 Project 小任务，先指定一个 CLI。找到结果文件、真实验证结果、未解决项和继续命令。
3. 在可丢弃材料中制造可解释的失败，例如错误的验证 argv 或缺少输入；自行读状态、诊断失败并修正。不要对真实项目注入破坏性故障。
4. 启动后台任务，观察事件并 stop。关闭终端，在第二个终端找回同一 Task，核对模式与已用预算并继续。
5. 隔天再次找回同一 Task，解释它已完成、待处理或需要核对的原因；需要时从材料恢复。记录是否求助及是否找到正确工作区。
6. 若具备第二个 CLI，完成跨 CLI 复核任务，逐条复现发现；记录误报、额外用量和手工交接。缺账号时记未测。
7. 自主决定是否在后续七天再次使用，不要求为了“完成观察”运行任务。记录有效观察天数和退出原因。
