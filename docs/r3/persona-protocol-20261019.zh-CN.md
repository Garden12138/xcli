# R3 三角色模拟试用协议 · 2026-10-19

按用户最新要求，本轮用户体验评审采用三个不同经验的 AI 角色分别试用并反馈，不再等待招募真人。本协议的完成条件是三个隔离角色完成可复现走查、区分实测与推测，并汇总反馈；不生成真实参与者证明或人类留存结论。

| 角色 | 经验假设 | 试用目标 |
| --- | --- | --- |
| novice | 首次接触 xcli，已有 Codex 使用经验 | 从帮助开始完成材料报告、找到产物、诊断输入路径错误 |
| regular | 熟悉 CLI、Git、JSON 和项目测试 | 修复缓存边界、确认真实测试与原仓库保护、理解 worktree 接收及错误 argv |
| expert | 资深工程师，重视脚本与恢复契约 | 实际 worker stop、同 Task 材料继续、预算与模式保持、事件顺序和完成后幂等 |

三个角色使用独立上下文，不继承此前讨论、收益对照结果或其他角色反馈；每个角色只读自己的说明、材料和运行结果。目录、XDG 配置/数据、项目、Go 缓存分别隔离。经验水平是提示词中的假设，角色本身仍是 AI，不能据此推断真实经验群体的行为分布。

被测候选为已通过归档和安装检查的 `0.5.0-r3-dev-c209756`，Darwin arm64 SHA-256 为 `b09b6de4292f9835729566ff5cd44531da0b1861821accd04eac5e67c4b51c33`。实际执行 xcli 命令、状态存储、Git worktree 与 Go 验证；Codex/Cursor 后端由现有确定性测试替身提供，避免把模型内容波动混入命令与生命周期走查。本轮原生模型调用为零，不能用替身的审查结果证明原生模型质量、登录或额度可用。

`tests/r3/persona_setup.py` 创建环境，入口只注入实验路径并 exec 真实候选；不更改长期配置或访问账号。其他 Adapter 指向不存在的路径，禁止角色直接调用真实 CLI、联网或读取主仓库实现。每个角色分别限制主要产品命令数量，保留失败证据；资深角色使用可控约五秒暂停捕获运行中的 worker。

```bash
python3 tests/r3/persona_setup.py --study /tmp/r3-personas --binary /path/to/candidate/xcli
```

反馈中的 observed 必须附实际命令、退出状态或产物；hypothesis 表示推测的用户阻力；fixture_limit 表示替身或实验的限制。不同任务和角色不能直接比较学习速度。隔天操作、七天留存、购买意愿、真人情绪和求助行为不虚构，未测项保持未测。原真实用户空表与历史原生预算账本不被这些模拟记录覆盖。

本轮评审完成后汇总可复现问题及建议，协作收益实验的既有无收益结论保持不变。后续若需要真实用户研究，可另行使用原参与者记录流程。
